Train Reservation and Information System
This project is a Java-based console application that simulates a simple train reservation and information system. It is designed to demonstrate core Java programming concepts through a real-world use case. The application allows users to enter travel details such as source station, destination station, and number of passengers, and then displays train details, seat availability, and total fare. The program follows a menu-driven approach, making it easy to use and understand.

Features
The system allows users to enter journey details, view available train information, calculate ticket fare based on the number of passengers, and check seat availability. It provides a basic reservation confirmation message after successful input. The logic is kept simple and suitable for beginners while still reflecting how an actual railway booking system works.

Technologies Used
Programming Language: Java
Concepts Used: Classes and Objects, Conditional Statements, Loops, Methods, Arrays / ArrayLists, Scanner for user input

How to Run the Project
Make sure Java is installed on your system. Clone or download the repository and navigate to the project folder. Compile the program using javac TrainProject.java and run it using java TrainProject. Follow the on-screen instructions to enter journey details and view results.

Sample Input
Source Station: Delhi
Destination Station: Jaipur
Number of Passengers: 3

Sample Output
Train Name: Express Line
Departure Time: 10:30 AM
Fare per Passenger: ₹450
Total Fare: ₹1350
Seats Available: Yes
Reservation Status: Confirmed

Project Use Case
This project is ideal for first- or second-year engineering students learning Java. It helps understand how programming concepts can be applied to solve real-life problems like railway reservations.

Future Enhancements
Possible improvements include adding a database for storing bookings, implementing ticket cancellation, adding different coach types (Sleeper, AC), simulating online payment, and developing a GUI using Java Swing or JavaFX.
