# 🚆 Train Reservation & Information System (Python)

## 📌 Project Overview
The **Train Reservation & Information System** is a Python-based application that allows users to interact with a simplified train system.  
Users can check train details, seat availability, fare information, and make basic reservations through a user-friendly command-line interface.

This project demonstrates core programming concepts and simulates a real-world railway booking scenario.

---

## 🎯 Features
- View available trains  
- Check source and destination routes  
- Display train timings  
- Seat availability check  
- Fare calculation  
- Reservation simulation  
- Input validation for better accuracy  

---

## 🛠️ Technologies Used
- **Programming Language:** Python  
- **Concepts Used:**  
  - Conditional statements  
  - Loops  
  - Functions  
  - Lists & Dictionaries  
  - User input handling
